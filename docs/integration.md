# Документация интеграции (Вариант 3)

## 1. Архитектура взаимодействия
Система состоит из 3 модулей, объединённых по стратегии сэндвич-интеграции:
- src/mod1.py — ввод коэффициентов a, b, c (верхний слой).
- src/mod2.py — решение квадратного уравнения (средний слой).
- src/mod3.py — проверка корней подстановкой (нижний слой).
- src/json_int.py — модуль маппинга и файлового обмена через JSON.

## 2. Схема потоков данных
data.json (k_a, k_b, k_c) -> zet2() маппинг -> mod2 (a, b, c) -> mod3 (roots) -> result.json

## 3. Протокол и форматы сообщений
- Уровень 1: прямой вызов функций (src/main.py).
- Уровень 2: файловый обмен данными в формате JSON (кодировка UTF-8).

## 4. Примеры запросов и ответов
Входной файл (data.json):
{"k_a": "1", "k_b": "-5", "k_c": "6"}

Выходной файл (result.json):
{"a": 1.0, "b": -5.0, "c": 6.0, "roots": [3.0, 2.0], "check_ok": true}
